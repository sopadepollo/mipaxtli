# Fuente empaquetada

`DejaVuSans.ttf` es la fuente que usa `io/signs.py` para componer el cuadro de
`lsm-signs reproducir`: viene de Debian/Ubuntu (`fonts-dejavu-core`), porque la
fuente por defecto de Pillow (Aileron) no tiene glifos para `Ñ`/`ñ` ni vocales
acentuadas y las dibuja como recuadros. La licencia va en
`DejaVuSans-LICENSE.txt`, junto al archivo.
